% Operand map: what each source register carries, per instruction. Mirrors

% accumulator. 64-bit sources are XIF dual-read register pairs (r:r+1); MXFINAL's
% two sources are plain 32-bit reads, which is exactly what lets the residue
% scales and accumulator fit without a third 64-bit port.

           into one register word.}
